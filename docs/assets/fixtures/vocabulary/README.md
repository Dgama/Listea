# Vocabulary acceptance fixture

A `listea.package/1` Package of four `vocabulary`/`1` Prompts. It is the acceptance fixture for
importing a vocabulary Todo and for checking the drill card on device.

## What it exercises

| Prompt | Pronunciation | Declared option order | Correct |
|---|---|---|---|
| `serendipity` | own Resource, `serendipity-audio` | `c, b, a` | `b` |
| `ubiquitous` | shared `common-audio` | `b, a, c` | `b` |
| `ephemeral` | shared `common-audio` | `a, c, b` | `a` |
| `meticulous` | none | `c, a, b` | `c` |

- **Order is the contract.** Every option list is deliberately not alphabetical and not grouped by
  the answer. A card that sorts or shuffles is wrong; the rows must appear in the declared order.
- **Shared Resource.** `ubiquitous` and `ephemeral` name the same Package Resource, `common-audio`.
  It is declared once and may be required by more than one Prompt.
- **Optional pronunciation.** `meticulous` declares no `audio` key. The card must draw without a
  Listen control and remain answerable.
- **Required pronunciation.** The other three mark the Resource `required: true`; deleting or
  renaming the MP3 before import must block the judgment rather than let the answer be recorded
  without the content.

## Import

1. Put this folder (the directory holding `.listea/`) where the app can see it.
2. Create a Todo with **Package** import.
3. Choose **Headless Template for Single Choice** as the Task Review. The same template governs a
   dating card and a vocabulary card because both declare `choice.single` and emit `choice.select`.

Matching content means the same file. Copy the folder; do not point the app at the source
directory in this repository if you intend to edit the fixture afterwards.

## Files

- `.listea/manifest.json` — the package envelope and the Prompt/Resource declarations.
- `prompts/*.json` — the four bodies.
- `media/serendipity.mp3`, `media/common.mp3` — generated by `generate_vocabulary.py` with ffmpeg;
  the bytes are committed.
