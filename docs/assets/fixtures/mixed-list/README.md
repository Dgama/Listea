# Mixed-List acceptance fixture

The media half of acceptance 6. Import this folder with **Folder as Task**, and each immediate
child becomes one Task:

- `single-pdf/` — one two-page PDF. A Task with one Asset.
- `media-mix/` — a PDF, a PNG and an MP4. A Task with three Assets of three kinds.

The prompt half comes from `../mixed/` (Package import: dating + vocabulary) and, for the add-on
row, from `../vocabulary/` or the same mixed Package with an add-on attached. Build one List from
the Catalog holding all of them:

1. the single-PDF Task;
2. the pdf/png/mp4 Task;
3. the dating Task;
4. the vocabulary Task;
5. a vocabulary Task whose Todo carries an add-on.

Then review it in Quick Review and in List Review, finish it, and read the exported text file. The
page order inside a Task must stay Content (when it has one), then Assets in file order, then the
add-on.

Both PDFs carry a real text layer — the coloured field is a drawn rectangle and the title and
subtitle are Helvetica text — so the PDF passage tools (C1/C2 from a PDF-scoped control) can be
used on this Task in the same walk. A Pillow-saved PDF is a bitmap in a PDF wrapper: the viewer
shows it, but nothing in it can be selected and the passage menu never appears, which is not what
the fixture is meant to exercise.

Bytes are generated by `generate_mixed_list.py` and committed.
