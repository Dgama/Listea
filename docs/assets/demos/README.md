# Demo media

Animated demos of Listea in use. Empty for now — nothing here yet.

Conventions for anything added:

- **Name it after what it shows**, in kebab-case: `review-flow.gif`, `quick-review-start.gif`.
- **Keep it small.** A GIF embedded in the README is downloaded by everyone who opens the repo
  page. Prefer a few seconds, cropped to the phone, under a couple of megabytes.
- **One idea per file.** A demo that shows three features is a demo nobody can link to.

Static screenshots belong in [`../screenshots/`](../screenshots) instead.
